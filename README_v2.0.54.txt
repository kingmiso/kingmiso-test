KingMiso v2.0.54

수정 내용
- 영지: 상단 HUD와 하단 메뉴 사이에 배경과 건물 버튼을 함께 배치했습니다. 이미지 비율을 유지하고 불필요한 아래 절벽 부분만 화면에 맞춰 조정합니다. 스크롤과 끌기 이동을 막고, 네 건물의 이름/진행 표시 위치를 다시 맞췄습니다.
- 메뉴: 둥글고 입체적인 새 그림 아이콘 5종. 기존 28px 아이콘 대신 53px 아이콘을 사용합니다.
- 업그레이드: 내용에 맞춘 팝업 높이로 버튼 위 빈 공간을 없앴습니다. 생산량/자원/진행 영역의 색감과 정보 크기를 조정했습니다. 작업자와 버튼 기능은 유지합니다.

업로드
압축을 풀어 모든 파일을 기존 index.html과 같은 위치에 업로드하고, 같은 이름의 파일은 교체합니다. 폴더를 만들거나 파일명을 바꾸지 마세요.
새 이미지 km_nav_round_v254.png도 반드시 함께 올려주세요.
이 파일은 업로드용 패키지이며 사이트에 직접 배포하지 않았습니다.

확인
360×580, 393×680, 430×740, 834×1112에서 영지 스크롤 방지, 이미지 비율, 진행 중 4개 건물 표시 위치를 검증했습니다.
팝업 표시, 건설 시작, 다이아 1개당 720초 가속, 취소 시 지불 자원 50% 반환, 채팅/메뉴 이동, 작업자 애니메이션 및 움직임 줄이기 설정을 확인했습니다.
기존 저장 데이터 및 경제 규칙은 변경하지 않았습니다. 실제 서버 로그인/동기화 검증은 로컬 검사에 포함되지 않습니다.
