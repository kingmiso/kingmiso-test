KingMiso v2.0.53 — 마스터 그래픽 기준 재구성

이번 판단
게임 기능 전체를 다시 만드는 대신, 저장 데이터·경제 규칙을 유지하고 그래픽과 UI 구조를 재구성했습니다.
마스터의 핵심은 파스텔색이 아니라 자연스러운 햇빛, 푸른 지붕과 금색 장식, 짙은 남색 UI, 선명한 금색/파란색 버튼, 작은 작업자입니다.

적용 범위
- 영지 배경을 새로 제작: 건물 사이 공간 확보, 원본 비율 유지, 왕성 지붕이 HUD 뒤에 잘리지 않게 배치.
- 하단 메뉴: 마스터에 맞춘 청보라색 기본 아이콘과 금색 선택 아이콘.
- 영지·채집 업그레이드 팝업: 화면 전체를 사용하는 독립된 세로 패널. 건물 전체 그림, 생산량, 비용, 시간, 단일 진행도, 작업자 그림, 가속/건설 버튼.
- 작은 화면에서는 정보와 버튼 공간에 맞춰 그림 크기 자동 조정. 작업 중 작업자 움직임과 진행 바 빛 효과. 움직임 줄이기 설정 준수.
- 가속(다이아 1개당 12분), 취소(지불 자원 50% 반환), 기존 저장 형식 유지.

업로드
1. KingMiso_v2.0.53_MasterRebuild.zip의 압축을 풉니다.
2. 안의 파일을 모두 기존 index.html과 같은 GitHub 저장소 위치에 업로드합니다.
3. 파일명은 바꾸지 말고 같은 이름은 교체합니다. 별도의 assets 폴더를 만들 필요 없습니다.
4. GitHub Pages 반영 후 새로고침하고 버전 v2.0.53을 확인합니다.
이 패키지는 업로드용 파일이며, 여기서 실제 사이트 배포를 실행한 것은 아닙니다.

검증
360×580, 393×680, 430×740, 834×1112 크기에서 확인.
건설 시작, 진행도/시간 표시, 가속 비용과 정확한 720초 단축, 중복 차감 방지, 50% 취소 반환, 채팅/메뉴 이동, 움직임 줄이기 설정 확인.
서버 로그인과 클라우드 동기화는 변경하지 않았으며 실제 서버 연결 검증은 이 로컬 검사에 포함되지 않습니다.
