KingMiso v2.0.55 — 따뜻한 왕국 UI

- 상하단 메뉴 뒤까지 이어지는 전체 화면 영지 배경. 주요 건물이 메뉴에 가려지지 않도록 하늘 여백을 포함해 배경을 새로 구성했습니다.
- 프로필/상단 자원/하단 메뉴 반투명 처리. 배경 비율 유지, 스크롤 없음.
- 자원 표시: K/M/B/T 표기에서 소수점 최대 두 자리. 실제 자원 데이터는 반올림하거나 변경하지 않습니다.
- 농장/금광/제재소/대장간: 각기 어울리는 따뜻한 컬러와 입체 효과, 큰 볼드 글씨. 왕성 버튼은 왕관과 금색 장식의 청색 버튼으로 강조.
- 미접속 자원 보상과 왕국 레벨업 축하창: 크림/살구색 배경, 그림 아이콘, 금색 확인 버튼. 기존 보상 계산 유지.
