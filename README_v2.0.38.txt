KingMiso v2.0.38 — 영지 전체 UI 및 채팅 화면

적용: ZIP을 풀고 기존 배포 폴더의 파일을 덮어씁니다. 실행 파일은 index.html입니다.

변경 사항
- 기존 KingMiso 시안에 맞춘 남색·금색 자원창, 일러스트 자원 아이콘, 하단 메뉴.
- 아이폰 세로형 영지 지도와 태블릿/컴퓨터 지도 표시.
- 건물별 전용 일러스트가 있는 상세창. 창 안의 닫기 버튼과 명확한 글자 색상.
- 실제 건설 상태에 연결된 진행률/남은 시간/완료 레벨/다음 건설 비용 표시.
- 하단 메뉴 바로 아래에 최근 대화 두 줄 표시.
- 최근 대화 터치 시 채팅 전용 페이지. 서버에 저장되어 있는 전체 대화 확인 및 전송.
- 기존 최근 20개 전달 제한 제거. 서버가 삭제한 대화는 복원할 수 없습니다.
- 전송 실패 시 입력문 보존, 전송 중 중복 요청 차단.

생산/강화 비용과 시간의 기존 계산 및 게임 저장 데이터 구조는 유지했습니다.
이번 버전은 영지·공통 HUD·건물 상세·채팅 작업이며, 영웅/전투 등 내부 화면의 전체 그래픽 전환은 별도입니다.

검증: Chromium 390x844 / 834x1112 / 1366x900에서 화면 및 상호작용 확인.
건설 시작, 진행, 완료 1회, 열린 상세창 갱신, 닫기, 최근 두 줄과 전체 35개 테스트 대화 표시,
전송 성공 및 실패 보존, 하단 메뉴 이동 확인. 전송 검사는 모의 서버로 수행.
실제 iOS Safari 및 사용자 계정 서버 연동은 배포 후 확인이 필요합니다.

그래픽: 기존 KingMiso 전체 시안을 참고하여 imagegen으로 제작한 자원 아틀라스,
네 생산 시설 상세 일러스트, 세로 영지 지도입니다.
